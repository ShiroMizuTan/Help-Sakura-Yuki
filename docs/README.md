## 关于

Namachokoretomusu 是一个 QQ 群聊机器人，提供签到、街机厅人数查询、商店、情侣关系等多种功能。

## 快速开始

绝大多数功能都需要以 `.` 开头，参数之间使用空格分隔。

### 使用规则

- 指令别名以 `Namachokoretomusu.Api/appsettings.json` 当前配置为准；本地部署可通过 `appsettings.local.json` 覆盖。
- 常规指令格式：`.指令 参数1 参数2`；不识别的指令不会回复。
- 参数含空格时可用中文引号包裹，例如 `.谱面预览 "Shiny Smily Story" ex`；引号不会作为参数内容传入，未闭合的左引号会将余下文本视为同一参数。
- `帮助` / `Help` / `help` 和单独发送 `雪希` / `Yuki`（大小写不敏感）支持**不加前缀**触发；此外，单独实际 @ 当前机器人且不附带文本时，也会触发呼叫回复。
- 带前缀的 `.帮助` 同样可用；呼叫回复是否支持带前缀名称，取决于当前配置是否包含 `Call` 别名。
- 群数据类功能（地点别名、人数上报、语录、每日老婆和 NTR 统计）会按群隔离；语录功能仅限群聊。

### 常用指令

| 指令 | 说明 |
|------|------|
| `帮助` / `雪希` | 帮助页 / 呼叫机器人（支持无前缀） |
| `.签到` | 每日签到，获取经验和金币 |
| `.jk` | 查看街机厅人数 |
| `.商店` | 查看可购买物品 |
| `.反馈 内容` | 提交反馈 |
| `.看图` | 获取随机图片 |
| `.随机语录` | 随机展示一条本群语录 |
| `.成员 时乃空` | 查询 Hololive 成员资料 |

::: tip
需要 @ 用户的指令必须使用 QQ 群中的实际艾特消息，不能只输入普通文本。
:::

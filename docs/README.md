## 快速开始

- 大多数指令以 `.` 开头，参数之间用空格分隔，含空格的参数可用中文引号包裹。
- 指令别名以 `appsettings.json` 当前配置为准；本地部署可通过 `appsettings.local.json` 覆盖。
- `帮助` / `雪希` 支持无前缀触发；@ 机器人且不附带文本时也会触发呼叫回复。
- 需要 @ 用户的指令必须使用 QQ 群中的实际艾特消息。
- 群数据类功能（地点别名、人数上报、语录、每日老婆和 NTR 统计）会按群隔离；语录功能仅限群聊。

::: tip
各功能页面有更详细的指令说明和示例。
:::

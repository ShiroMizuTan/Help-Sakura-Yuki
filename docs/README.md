## 关于

Namachokoretomusu 是一个 QQ 群聊机器人，提供签到、街机厅人数查询、商店、情侣关系等多种功能。

## 快速开始

所有指令以 `.` 为前缀，参数之间使用空格分隔。

### 常用指令

| 指令 | 说明 |
|------|------|
| `.签到` | 每日签到，获取经验和金币 |
| `.jk` | 查看街机厅人数 |
| `.商店` | 查看可购买物品 |
| `.反馈 内容` | 提交反馈 |
| `.看图` | 获取随机图片 |

::: tip
需要 @ 用户的指令必须使用 QQ 群中的实际艾特消息，不能只输入普通文本。
:::

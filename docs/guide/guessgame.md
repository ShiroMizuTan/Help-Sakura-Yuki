# 猜大小

押上金币，赌三颗骰子的和值大小。

## 指令

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `猜大` / `押大` | 金额 | `.猜大 100` | 押「大」，赌和值为 11~18 |
| `猜小` / `押小` | 金额 | `.猜小 100` | 押「小」，赌和值为 3~10 |

## 玩法

掷 3 颗六面骰，和值必然落在 3~18：

| 结果 | 和值范围 | 概率 |
|------|------|------|
| 小 | 3 ~ 10 | 50% |
| 大 | 11 ~ 18 | 50% |
| 豹子（三颗点数相同） | —— | 约 2.78%（1/36） |

- **中了**：投入翻倍返还。押 100 中了 → 返还 200，净赚 100
- **没中**：投入清空。押 100 没中 → 扣掉 100
- **豹子庄家通吃**：三颗点数相同时，押哪边都输

::: tip
豹子是本游戏唯一的抽水来源（期望值约 −2.78%），作用是让金币缓慢回收而非无限膨胀。

和值分布天然左右对称（3 与 18 同为 1/216，10 与 11 同为 27/216），
所以「大」「小」概率**恰好各 50%**，不需要额外调概率。
:::

## 回复示例

```
骰子 4 2 5，和值 11 → 大
押「大」中了！
投入 100 → 返还 200（净赚 100）
余额 1100 金币（今日 3/10 次）
```

## 配置项

| 键 | 默认值 | 说明 |
|------|------|------|
| `GuessGame:MaxBet` | `1000` | 单次最大投入金币。`<= 0` 表示不限制 |
| `GuessGame:MaxPerDay` | `10` | 每人每日最多对局次数（按东八区日期）。`<= 0` 表示不限制 |

## 约定与限制

- 金额必须为正整数；超过单次上限会被拒绝
- 每日限次按用户 + 日期统计，用完后当日不再受理
- 余额不足会被拒绝，**不会出现负余额**
- 对局、余额变更与流水写入在**一次数据库事务**内完成

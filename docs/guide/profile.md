# 资料与头像

## 查看资料

| 指令 | 示例 | 说明 |
|------|------|------|
| `我的信息` | `.我的信息` | 查看自己的资料卡 |

资料卡里包含你的昵称、等级、经验、升级进度、金币和头像。

## 设置头像

| 指令 | 示例 | 说明 |
|------|------|------|
| `设置头像` / `换头像` / `改头像` | 见下方说明 | 把一张图片设为自己的头像 |
| `恢复头像` / `默认头像` / `还原头像` | `.恢复头像` | 恢复成默认头像 |
| `我的头像` / `查看头像` / `头像` | `.我的头像` | 单独发送自己现在的头像 |

::: tip 怎么设置头像
**在一张图片上回复这条指令**，也就是说：

1. 先发一张图片
2. 在这条图片消息上回复 `.设置头像`

不能空发 `.设置头像`，那样没有图片可用。
:::

## 头像的几种状态

| 状态 | 说明 |
|------|------|
| 默认头像 | 刚使用时的状态，显示你的 QQ 头像 |
| 自己设的头像 | 用 `.设置头像` 换过之后，就一直显示这张 |
| 恢复默认 | 用 `.恢复头像` 退回默认状态 |

::: tip 换 QQ 也不影响
自己设的头像保存在服务器上，跟你的账号走，不依赖 QQ 号。
:::

## 常见问题

**Q：图片要多大？**
有大小限制，太大的图片会被拒绝，换一张小一点的就行。

**Q：为什么设不了头像？**
检查一下是不是没有在图片消息上回复，而是单独发了一条指令。

**Q：我的头像会出现在哪里？**
资料卡上会显示你设置的头像。舞萌的 Best 50 / AP 50 卡片上也会显示玩家的头像。

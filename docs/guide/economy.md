# 经济流转

金币可以在用户之间流动，也可以把背包里的物品送给别人。

::: warning
以下指令中的目标用户**必须使用实际 @**。@ 不会出现在文本里，但参数解析不受影响。
:::

## 转账

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `转账` / `转金币` / `给钱` | 实际 @ 用户 + 金额 | `.转账 @小明 100` | 把自己的金币转给对方 |

## 赠送物品

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `赠送` / `送给` / `送礼` | 实际 @ 用户 + 物品名 [+ 数量] | `.赠送 @小明 好感药水 3` | 把自己的物品送给对方 |

## 金币榜

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `金币榜` / `金币排行` / `金币排行榜` / `富豪榜` | 无 | `.金币榜` | 展示金币最多的前 5 名 |

榜单按金币降序取前 5 名，**金币为 0 的用户不参与排名**；金币相同时先注册的靠前，名次稳定。
榜单只读，查看榜单**不会给自己建号**。

## 约定与限制

- 金额与数量必须为正；单次转账金额上限 **100000 金币**
- 不能转账 / 赠送给自己
- 发送方余额或持有量不足会被拒绝
- 接收方背包中该物品已达堆叠上限时会拒绝赠送，**不会静默丢弃**
- 转账与赠送都只在**一次数据库事务**内完成，不会出现「扣了钱对方没收到」
- 钱包 / 背包的增减与物品流转都不改变任何一方的平台绑定关系

::: tip
所有涉及金币的操作（签到 / 购买 / 转账 / 刮刮乐 / 猜大小）对同一用户是**串行执行**的，
并发下不会算错账。
:::

::: warning
仅管理员可以执行。
:::

|------|------|------|------|
| `创建物品` / `新增物品` | `名称 描述 价格 效果类型 [效果值]` | `.创建物品 红包 金币奖励 100 CoinGift 50` | 创建商店物品 |

| 指令 | 说明 |
|------|------|

## 购买

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `购买` / `买` | `物品名称` | `.购买 红包` | 使用金币购买物品 |
| `购买` / `买` | `物品名称 数量` | `.购买 红包 5` | 一次购买多个（数量缺省为 1） |

一次性购买多个时，总价 = 单价 × 数量。**余额不足或超出堆叠上限时整笔拒绝**，不会部分成交。

## 使用物品

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `使用` / `使用物品` | `物品名称` | `.使用 红包` | 使用物品 |
| `使用` / `使用物品` | `物品名称` + 实际 @ 用户 | `.使用 好感药水 @小明` | 对被 @ 用户使用物品 |

::: tip
使用失败（未 @ 目标、每日限次用尽、奖池未配置等）**不会消耗物品**。
:::

## 支持的效果类型

| 效果类型 | 参数示例 | 说明 |
|------|------|------|
| `None` | `0` | 无效果 |
| `AffinityBoost` | `10` | 增加对目标用户的好感度，需实际 @ 目标 |
| `CoinGift` | `50` | 增加**使用者自己**的金币（历史行为，不认 @ 目标） |
| `ExpBoost` | `{"multiplier":2,"duration_hours":1}` | 授予限时经验加成，见下节 |
| `ScratchCard` | `0` | 刮刮乐抽奖一次，奖池来自 `ScratchCard` 配置节 |

::: warning
`ExpBoost` 的效果值必须是**不带空格**的 JSON。`创建物品` 的参数按空白切分，
写成 `{ "multiplier": 2 }`（带空格）会被切成多个参数导致解析失败。
也接受纯数字简写（如 `2`），此时持续时间取默认 1 小时。
:::

## 经验加成（ExpBoost）

使用带 `ExpBoost` 效果的道具后，会写入一条限时增益。增益期间：

- **签到**获得的经验按倍率结算
- **上报街机**获得的经验按倍率结算
- **刮刮乐**抽到的经验同样加成

签到成功时会额外提示「经验加成 ×N 生效中」。

## 刮刮乐（ScratchCard）

商店上架一个 `EffectType` 为 `ScratchCard` 的道具（建议名「刮刮卡」），用户 `.使用 刮刮卡` 即抽奖一次。

抽奖流程：每日限次校验 → 扣金币 → 权重抽奖 → 发奖 → 写流水，全部合并为**一个事务**，
不会出现「扣了钱没发奖」。

| 配置项 | 默认值 | 说明 |
|------|------|------|
| `ScratchCard:Price` | `100` | 单次抽奖花费的金币 |
| `ScratchCard:MaxPerDay` | `10` | 每用户每日最多抽奖次数（按东八区日期），≤0 表示不限 |
| `ScratchCard:Prizes` | 见配置 | 奖池，每项含 `Kind` / `Amount` / `ItemName` / `Weight` |

奖项 `Kind` 支持三类，`Weight` 是**相对权重**（不是百分比，总和不必为 100，≤0 的条目不参与抽奖）：

| Kind | 说明 |
|------|------|
| `Coins` | 奖励 `Amount` 金币 |
| `Exp` | 奖励 `Amount` 经验（同样受 ExpBoost 倍率加成） |
| `Item` | 奖励 `ItemName` 指定的物品 ×`Amount`；物品已达 `MaxStack` 时降级为空奖 |

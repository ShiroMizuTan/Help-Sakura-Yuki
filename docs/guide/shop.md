# 商店与背包

## 创建物品

::: warning
仅管理员可以执行。
:::

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `创建物品` / `新增物品` | `名称 描述 价格 效果类型 [效果值]` | `.创建物品 红包 金币奖励 100 CoinGift 50` | 创建商店物品 |

## 商店

| 指令 | 说明 |
|------|------|
| `商店` / `商城` | 查看可购买物品 |

## 购买

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `购买` / `买` | `物品名称` | `.购买 红包` | 使用金币购买物品 |

## 背包

| 指令 | 说明 |
|------|------|
| `背包` / `仓库` | 查看自己的物品 |

## 使用物品

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `使用` / `使用物品` | `物品名称` | `.使用 红包` | 使用物品 |
| `使用` / `使用物品` | `物品名称` + 实际 @ 用户 | `.使用 好感药水 @小明` | 对被 @ 用户使用物品 |

## 效果类型

| 效果类型 | 参数示例 | 说明 |
|----------|----------|------|
| `None` | `0` | 无效果 |
| `AffinityBoost` | `10` | 增加对目标用户的好感度 |
| `CoinGift` | `50` | 增加使用者金币 |
| `ExpBoost` | `10` | 暂无对应效果 |

# 问候语管理

::: warning
以下指令仅管理员可以执行。
:::

## 增加问候语

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `增加问候语` / `增加问候` / `添加问候语` / `添加问候` / `新增问候` / `新增问候语` | `时段 内容` | `.增加问候语 早上好 今天也要加油` | 添加签到问候语 |

## 列出问候语

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `列出问候语` / `列出问候` / `问候列表` / `查看问候` | 无 | `.列出问候` | 查看全部问候语 |
| 同上 | `时段` | `.列出问候 早上好` | 查看指定时段的问候语 |

## 删除问候语

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `删除问候语` / `移除问候` | `问候语 ID` | `.删除问候语 12` | 删除指定 ID 的问候语 |

## 支持的时段参数

| 时段 | 可用写法 |
|------|----------|
| 早上 | `早上好`、`早安`、`早`、`morning` |
| 下午 | `下午好`、`午安`、`午`、`afternoon` |
| 晚上 | `晚上好`、`晚安`、`晚`、`evening` |

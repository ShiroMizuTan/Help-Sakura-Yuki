# 街机厅

## 地点与别名

### 查找地点

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `查找地点` / `找地点` / `查地点` | `关键词` | `.查找地点 秋叶原` | 按名称、地址或省份搜索街机厅 |

### 添加别名

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `添加别名` / `新增别名` | `别名 地点ID` | `.添加别名 秋叶原 12345` | 为街机厅设置当前群别名 |

先用 `.查找地点` 获取地点 ID，再用 `.添加别名 别名 地点ID`。

### 删除别名

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `删除别名` / `移除别名` | `别名` | `.删除别名 秋叶原` | 删除当前群的指定别名 |

### 别名列表

| 指令 | 说明 |
|------|------|
| `别名列表` / `列出别名` | 查看地点别名 |

## 人数查询

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `jk` | 无 | `.jk` | 查看当前群最近 4 小时所有地点的最新上报 |
| `jk` | `别名` | `.jk cw` | 查看指定别名的最新人数详情 |
| `jk` | `小时数` | `.jk 8` | 查看最近 8 小时所有地点的上报 |
| `jk` | `别名 小时数` | `.jk cw 4` | 查看指定别名最近 4 小时的上报 |
| `查询人数` / `多少人` | `别名 小时数` | `.查询人数 cw 4` | 查询指定别名最近 N 小时的上报 |

::: tip
`.jk` 后的别名和小时数均为可选参数。
:::

## 人数上报

### 普通上报

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `上报` / `上报人数` | `别名 人数` | `.上报 cw 20` | 直接上报当前人数 |
| `上报` / `上报人数` | `别名 + 人数` | `.上报 cw +5` | 在最近一次人数基础上增加人数 |
| `上报` / `上报人数` | `别名 - 人数` | `.上报 cw -3` | 在最近一次人数基础上减少人数 |
| `上报` / `上报人数` | `别名 = 人数` | `.上报 cw =18` | 直接设置当前人数 |

普通上报的人数上限为：`机器数量 × 30`。

::: tip
上报支持快捷格式：`.别名+数字`、`.别名-数字`、`.别名=数字`。
:::

### 强制上报

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `强制上报` / `强制` | `别名 人数` | `.强制上报 cw 500` | 跳过合理人数检查后上报（当前实现未限制管理员） |
| `强制上报` / `强制` | `别名 操作符 人数` | `.强制上报 cw +100` | 强制执行加、减或赋值上报 |

## 无前缀匹配

群主 / 群管理员 / Bot 管理员可以为当前群开启无前缀匹配。开启后，群成员可以**不带 `.` 前缀**直接使用街机厅指令：

| 写法 | 示例 | 说明 |
|------|------|------|
| `<别名>数字` / `<别名>±数字` | `cw1`、`cw+5`、`cw-3`、`cw=18` | 免前缀上报人数，等价于 `.cw1` 等粘连格式 |
| `上报 别名 人数` | `上报 cw 20` | 免前缀上报，参数必须完整（别名 + 人数），否则不响应 |
| `<别名>几` | `cw几` | 查询单店人数详情 |
| 查询类指令 | `别名列表`、`多少人 cw` | 免前缀查询（`查找地点`、`查询人数`、`别名列表`、`多少人` 等） |

| 指令 | 示例 | 权限 | 说明 |
|------|------|------|------|
| `开启街机无前缀` / `启用街机无前缀` | `.开启街机无前缀` | 群主 / 群管理员 / Bot 管理员 | 为当前群开启无前缀匹配 |
| `关闭街机无前缀` / `停用街机无前缀` | `.关闭街机无前缀` | 群主 / 群管理员 / Bot 管理员 | 为当前群关闭无前缀匹配 |

::: warning
- 无前缀匹配仅限 QQ 群聊，且**默认关闭**，需要手动开启
- 触发词不匹配或格式不完整时 Bot 静默不响应
- 写类管理指令（添加别名 / 删除别名 / 强制上报）不在无前缀范围内，仍需 `.` 前缀
:::

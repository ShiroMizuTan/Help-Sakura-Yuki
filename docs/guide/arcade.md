## 人数查询

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `jk` | 无 | `.jk` | 查看当前群最近 4 小时所有地点的最新上报 |
| `jk` | `别名` | `.jk cw` | 查看指定别名的最新人数详情（**文字与街机厅信息卡合成一条消息**） |
| `jk` | `小时数` | `.jk 8` | 查看最近 8 小时所有地点的上报 |
| `jk` | `别名 小时数` | `.jk cw 4` | 查看指定别名最近 4 小时的上报 |
| `查询人数` / `多少人` | `别名` | `.查询人数 cw` | 查询指定别名的最新一条上报 |
| `查询人数` / `多少人` | `别名 小时数` | `.查询人数 cw 4` | 查询指定别名最近 4 小时内的上报 |
| `几` | `<别名>几` | `.cw几` | 同「查询别名」，带前缀写法 |

::: tip
`.jk` 后的别名和小时数均为可选参数。

两点容易误解的地方：

- **「N 小时」是筛选窗口，不是条数**。`.jk cw 4` 是「最近 4 小时**之内**的上报」，每家店仍然只返回**最新一条**，不是返回 4 条。省略小时数等价于「查最新一条」。
- 带别名的查询只发**一条**消息：先是文字（人数 / 机器数 / 上报时间），后接街机厅信息卡图片。截图失败时会自动降级成纯文字，不会不响应。
:::

## 人多人少看不了的时候

上报是大家随手报上来的，所以总会遇到「这家店好久没人上报」的情况——闭店、机器维护、或者大家都忘了报。

这时查询不会只回一句「暂无数据」，而是会**给出一个人数估计**，并明确标注这是估计值：

> ⚠️ 最新上报已过 2 小时，以下为历史统计估计（非实时）
> cw 估计：约 35 人（通常 28-44 人）
> 依据：同店 6 场历史中位数

::: tip
关于这个估计值：

- **有实测就用实测的**。2 小时内的上报永远是真实数据，预测不会去覆盖它。
- 估计区间跨度大时会给区间（如 `28-44`），不给一个看似精确的数字。误差确实有二十多趴。
- 这类数字**只用于显示**，不会被当成上报记录。所以下一次 `.上报 cw +5` 的加减基准仍然是你上一次真实上报的值，不会被估计值带偏。
:::

::: warning
估计不出来的时候机器人会直说原因，不会瞎编一个数字。常见原因是：该店近期完全没人上报过、当前时间不在营业时段、或者该店历史数据太少。

另外，**这个功能默认是关闭的**，需要机器人管理员开启才会出现估计值。关闭时查询仍会提示「数据可能已过期」。
:::

## 人数上报

### 普通上报

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `上报` / `上报人数` | `别名 人数` | `.上报 cw 20` | 直接上报当前人数 |
| `上报` / `上报人数` | `别名 + 人数` | `.上报 cw +5` | 在最近一次人数基础上增加人数 |
| `上报` / `上报人数` | `别名 - 人数` | `.上报 cw -3` | 在最近一次人数基础上减少人数 |
| `上报` / `上报人数` | `别名 = 人数` | `.上报 cw =18` | 直接设置当前人数 |

普通上报的人数上限为：`机器数量 × 30`（该店没有机器数信息时按 200 人算）。

::: tip
上报支持快捷格式：`.别名+数字`、`.别名-数字`、`.别名=数字`。
:::

::: warning
关于人数校验，有三点需要知道：

- **上限卡的是上报后的最终人数**。所以 `+` / `-` 累加同样受限制，不能靠多次 `.上报 cw +30` 一点点挤上去。
- **非数字和负数会被直接拒绝**。`.上报 cw abc`、`.上报 cw -5` 会提示错误并且**不写入记录**，也不会发放金币奖励。
- **`0` 是合法上报**。上报的人走了、店里没人了，就是 0 人。不要因为看到 0 就以为上报坏了。
:::

### 强制上报

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `强制上报` / `强制` | `别名 人数` | `.强制上报 cw 500` | 跳过合理人数检查后上报（当前实现未限制管理员） |
| `强制上报` / `强制` | `别名 操作符 人数` | `.强制上报 cw +100` | 强制执行加、减或赋值上报 |

## 无前缀匹配

群主 / 群管理员 / Bot 管理员可以为当前群开启无前缀匹配。开启后，群成员可以**不带 `.` 前缀**直接使用街机厅指令：

| 写法 | 示例 | 说明 |
|------|------|------|
| `<别名>数字` / `<别名>±数字` | `cw1`、`cw+5`、`cw-3`、`cw=18` | 免前缀上报人数，等价于 `.cw1` 等粘连格式 |
| `上报 别名 人数` | `上报 cw 20` | 免前缀上报，参数必须完整（别名 + 人数），否则不响应 |
| `<别名>几` | `cw几` | 查询单店人数详情 |
| 查询类指令 | `别名列表`、`多少人 cw` | 免前缀查询（`查找地点`、`查询人数`、`别名列表`、`多少人` 等） |

| 指令 | 示例 | 权限 | 说明 |
|------|------|------|------|
| `开启街机无前缀` / `启用街机无前缀` | `.开启街机无前缀` | 群主 / 群管理员 / Bot 管理员 | 为当前群开启无前缀匹配 |
| `关闭街机无前缀` / `停用街机无前缀` | `.关闭街机无前缀` | 群主 / 群管理员 / Bot 管理员 | 为当前群关闭无前缀匹配 |

::: warning
- 无前缀匹配仅限 QQ 群聊，且**默认关闭**，需要手动开启
- 触发词不匹配或格式不完整时 Bot 静默不响应
- 写类管理指令（添加别名 / 删除别名 / 强制上报）不在无前缀范围内，仍需 `.` 前缀
:::

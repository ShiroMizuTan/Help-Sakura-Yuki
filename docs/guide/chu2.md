# 中二节奏（CHUNITHM）

以下功能查询中二节奏的曲库、谱面和玩家成绩。所有指令都需要 `.` 前缀。

中二和舞萌是两套独立的数据，指令不通用，但**共用同一份账号授权** —— 见下方「账号绑定」。

## 曲库与谱面

| 指令 / 格式 | 参数 | 示例 | 说明 |
|---|---|---|---|
| `查曲` / `中二查曲` | `曲名/别名/定数/曲师/谱师/分类 [页码]` | `.查曲 幾四音`、`.查曲 14.7` | 搜索歌曲；单曲发谱面信息卡，多曲发分页图片 |
| `中二id` | `曲目 ID` | `.中二id 8000` | 按曲目 ID 查谱面信息卡 |

搜索时不需要指定搜什么，机器人会自动按这几个维度匹配：

| 输入 | 匹配什么 |
|---|---|
| 曲名 | 精确匹配，匹配不上再退回到包含匹配 |
| 别名 | 同上 |
| 定数 | `14.7`（精确）或 `14`（该难度等级的全部谱面） |
| 难度标级 | `14+` 这样的写法 |
| 曲师 / 分类 | 精确匹配 |
| 谱师 | 精确匹配 |

::: tip
定数是**精确匹配**，没有「13 以上」这种范围搜索 —— 想找 13 以上的谱面，只能一个等级一个等级地查（`.查曲 13`、`.查曲 14`…）。
:::

::: tip
结果分三种情况：

- **只找到 1 首** → 直接发谱面信息卡
- **找到 2~5 首** → 纯文本列出（比图片轻）
- **找到更多** → 发分页图片，每页 60 首，可在指令末尾加页码翻页（`.查曲 初音 2`）

谱面信息卡会显示曲名、艺术家、分类、BPM、各难度定数、谱师、物量，以及**你自己**在这首曲上的成绩（如果查得到）。
:::

::: warning
**中二的别名库只覆盖约一半的曲子**，而且没有第二个数据源能补齐。所以搜不到的时候，多半是别名没收录 —— 试试曲名原文，或者换个更短的关键词。

另外中二有 **49 首曲子存在重名**（原曲和它的 WORLD'S END 版同名），所以搜到多首是正常情况，机器人不会替你随便挑一首，会把候选都列出来让你选。
:::

## 玩家成绩

| 指令 | 参数 | 示例 | 说明 |
|---|---|---|---|
| `中二b30` / `c30` / `C30` | 无 | `.c30` | 查询自己的 Rating 构成（Best 30 + 新曲 Best 20 两段一起出） |
| `中二n20` / `n20` / `N20` / `c20` | 无 | `.n20` | 只看「新曲 Best 20」那一段 |
| `中二选择` / `中二selection` / `csel` | 无 | `.csel` | 查询 Selection 10 |
| `中二分数列表` / `cscore` | `[页码]` | `.cscore`、`.cscore 2` | 查询自己的全部成绩，可翻页 |
| `中二数据源` | `落雪` / `水鱼` / `自动` | `.中二数据源 落雪` | 设置自己的数据源偏好，只影响自己 |

::: tip
**中二的 RATING 由两段构成**：

| 段 | 是什么 |
|---|---|
| Best 30 | 非当前版本谱面里RATING 最高的 30 首 |
| 新曲 Best 20 | 当前版本常规谱面里 RATING 最高的 20 首 |

两段相加（最多 50 首）后取**平均值**得到总 RATING。所以 `.c30` 会把两段一起出，
只想看新曲那一段就用 `.n20`。WE 谱面不参与 RATING 计算。

段标题只给「段名 + 首数」，不堆中间计算值 —— 因为总 RATING 是平均值，不是把两段加起来。
:::

::: tip
**Selection 10** 是 Best 30 以外、理论上还有机会进 b30 的那 10 首成绩，和上面两段是独立的东西。
:::

不带参数执行 `.中二数据源` 会显示当前设置和曲库来源。

成绩查询默认「**落雪优先**」—— 中二玩家绝大多数在落雪，而且只有落雪那边有别名、物量、收藏品和曲绘。落雪查不到时会自动切到水鱼。想要固定用某一边就用 `.中二数据源` 改。

## 账号绑定

| 指令 | 参数 | 示例 | 说明 |
|---|---|---|---|
| `绑定落雪` / `落雪绑定` / `bindlxns` | 无 | `.绑定落雪` | 生成落雪授权链接（权限：读取玩家数据） |

::: tip
**中二没有单独的绑定指令。** 落雪授权同时覆盖舞萌和中二，执行一次 `.绑定落雪`，**两个游戏一起生效**，不需要绑两遍。
:::

绑定后先去 [落雪咖啡屋](https://maimai.lxns.net/) 确认你的中二节奏数据已经同步过 —— 只在游戏里打了分但没同步，机器人这边是查不到的。

## 常见问题

**Q：查不到我的成绩？**
按顺序检查这几点：

1. 有没有执行过 `.绑定落雪`（未绑定时分数列表只显示完成标记，不显示分数）
2. 有没有去落雪咖啡屋同步过中二数据
3. 换个数据源试试：`.中二数据源 水鱼`

**Q：分数列表只显示打没打过，不显示分数？**
说明还没绑定落雪。执行 `.绑定落雪` 就能看到分数和 RATING 了。

**Q：为什么会提示「请求过于频繁」？**
查询太密集了，稍等一会儿再试。

**Q：提示「曲库数据尚未就绪」？**
曲库正在同步或上次同步失败了，稍等再试。如果一直出现，请让机器人管理员检查。

## 目前没有的功能

以下功能因为上游接口限制暂时做不了，不是遗漏：

| 功能 | 原因 |
|---|---|
| Recent 50 | 上游对应接口已废弃 |
| RATING 趋势图 | 上游未开放权限 |
| 成绩热力图 | 同上 |
| 定数完成表 / 难度进度表 | 上游没有按条件筛选的接口 |
| 收藏品（称号 / 名牌 / 头像） | 中二的达成条件结构和舞萌完全不同，需要单独设计 |

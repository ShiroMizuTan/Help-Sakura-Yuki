# 随机色图

::: tip
该指令必须带 `.` 前缀，聊天中偶然出现关键词不会触发。
:::

## 获取随机图片

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `setu` / `色图` / `来份色图` | 无 | `.setu` | 随机获取一张 Pixiv 插图 |
| `setu` | `标签` | `.setu 猫` | 按标签筛选图片 |
| `setu` | `标签 标签` | `.setu 白丝 制服` | 多个标签同时匹配 |

## 标签写法

| 写法 | 示例 | 说明 |
|------|------|------|
| 单个标签 | `.setu 猫` | 匹配带有该标签的作品 |
| 多个标签 | `.setu 猫 白丝` | 需同时满足全部标签，最多 3 个 |

同一个标签内可以用 `|` 表示「满足其一」，例如 `.setu 萝莉|少女` 会匹配带有萝莉或少女标签的作品。

## 说明

- 每次返回一张图片，并附带作品标题、PID 和作者。
- 每人有 15 秒冷却，冷却中会提示剩余秒数。
- 未命中标签时会提示「没有找到相关作品」，更换标签重试即可。

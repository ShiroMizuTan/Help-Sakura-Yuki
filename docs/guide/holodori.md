# Holodori / hololive 偶像资料

::: tip
以下功能优先使用 holodori.best 在线数据（数据最新、含简体中文名），API 不可用或未命中时自动回退本地 JSON 数据库（需要正确配置 `Holodori:DataDir`，并确保数据目录中存在 `version.txt`）；排行榜为实时在线数据。搜索支持中文、英文、ID 和模糊匹配。
:::

## 卡牌

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `卡牌` | `卡牌名` | `.卡牌 We are hololive!` | 查询唯一匹配卡牌的详情（稀有度、属性、主属性、数值权重、最大等级与开花）；无法唯一匹配时列出候选 |
| `卡牌搜` / `搜卡牌` / `查找卡牌` | `关键词` | `.卡牌搜 彩虹` | 搜索并列出最多 10 张匹配卡牌 |

## 歌曲

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `歌曲` / `查歌曲` | `歌名` | `.歌曲 Shiny Smily Story` | 查询歌曲详情（分类、时长、各难度等级） |
| `歌曲难度` / `查谱面` / `难度` | `等级（1-30）` | `.歌曲难度 22` | 列出指定等级的全部谱面 |
| `谱面预览` | `乐曲名或 ID [难度]` | `.谱面预览 "Shiny Smily Story" ex` | 下载并发送歌曲谱面预览图；不填难度时优先 Expert，否则选最高可用难度（本地数据） |

## 活动与成员排行榜（实时）

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `活动排行` / `活动榜` / `活动排行榜` | `[活动名 / 章节序号]` | `.活动排行` 或 `.活动排行 Spotlight` 或 `.活动排行 3` | 查询当前活动进行中章节的排行榜（截止线 #500/#1000/#5000/#10000/#25000 + Top 10）；不填参数默认当前活动最新章节，也可按活动名关键词或章节序号指定 |
| `成员排行` / `成员榜` / `评分榜` | `成员名` | `.成员排行 Ina'nis` | 查询指定 holomem 的评分排行榜；成员名支持中英文和昵称模糊匹配，多匹配时列出候选 |
| `排行榜帮助` / `排行帮助` | 无 | `.排行榜帮助` | 查看排行榜指令用法 |

::: tip
服务器区域在 `HolodoriRank:Region` 配置（`us` 美服 / `as` 亚服 / `jp` 日服）；数据源 holodori.best，有数十分钟延迟。
:::

## 成员（本地数据）

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `成员` / `查成员` / `holomem` | `成员名` | `.成员 时乃空` | 查询成员所属分组、生日、出道、粉丝名和社交链接等资料 |
| `成员列表` / `成员一览` | 无 | `.成员列表` | 按出道批次列出全部 Hololive 成员 |

## 剧情

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `剧情` | `章节 第x话` | `.剧情 1 第3话` | 按章节和话数查看主线剧情；剧情以转发消息形式发送 |

## 数据状态

| 指令 | 示例 | 说明 |
|------|------|------|
| `数据状态` / `游戏数据` | `.数据状态` | 查看本地数据库版本、数据目录及卡牌/歌曲/成员统计；数据加载失败时会提示检查 `Holodori:DataDir` |

::: tip
`谱面预览` 的难度参数可用 `e` / `easy`、`n` / `normal`、`h` / `hard`、`ex` / `expert`。卡牌、歌曲和成员查询在没有唯一匹配时会返回候选列表；关键词可以包含空格。
:::

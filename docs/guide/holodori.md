# Holodori / hololive 偶像资料

::: tip
以下功能使用本地 Holodori JSON 数据库，首次查询时加载；需要正确配置 `Holodori:DataDir`，并确保数据目录中存在 `version.txt`。搜索支持中文、英文、ID 和模糊匹配。
:::

## 卡牌

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `卡牌` | `卡牌名` | `.卡牌 We are hololive!` | 查询唯一匹配卡牌的详情；无法唯一匹配时列出候选 |
| `卡牌搜` / `搜卡牌` / `查找卡牌` | `关键词` | `.卡牌搜 天音` | 搜索并列出最多 10 张匹配卡牌 |

## 歌曲

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `歌曲` / `查歌曲` | `歌名` | `.歌曲 Shiny Smily Story` | 查询歌曲、歌手、制作人员、时长、难度和 MV 等信息 |
| `歌曲难度` / `查谱面` / `难度` | `等级（1-30）` | `.歌曲难度 22` | 列出指定等级的全部谱面 |

## 成员

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `成员` / `查成员` / `holomem` | `成员名` | `.成员 时乃空` | 查询成员所属分组、生日、出道、粉丝名和社交链接等资料 |
| `成员列表` / `成员一览` | 无 | `.成员列表` | 按出道批次列出全部 Hololive 成员 |

## 数据状态

| 指令 | 示例 | 说明 |
|------|------|------|
| `数据状态` / `游戏数据` | `.数据状态` | 查看本地数据库版本、数据目录及卡牌/歌曲/成员统计 |

::: tip
卡牌、歌曲和成员查询在没有唯一匹配时会返回候选列表；关键词可以包含空格。数据状态指令会在数据加载失败时提示检查 `Holodori:DataDir`。
:::

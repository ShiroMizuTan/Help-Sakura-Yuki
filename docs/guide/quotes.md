# 群语录

::: tip
语录数据、点赞和排行榜均按群隔离，仅能在群聊中使用。
:::

## 收录语录

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `收录` / `收录语录` | `内容` | `.收录 今天也要努力` | 收录一条本群语录，并记录收录者和时间 |

## 查看语录

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `随机语录` | 无 | `.随机语录` | 随机展示一条本群已收录语录 |
| `查看语录` | `语录 ID` | `.查看语录 12` | 按编号查看本群语录 |

## 点赞

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `点赞` | `语录 ID` | `.点赞 12` | 为指定语录点赞；同一用户不可重复点赞 |
| `取消点赞` | `语录 ID` | `.取消点赞 12` | 取消自己对指定语录的点赞 |

## 排行

| 指令 | 示例 | 说明 |
|------|------|------|
| `语录排行` / `语录收录榜` | `.语录排行` | 查看本群前十名语录收录者 |
| `语录热度榜` | `.语录热度榜` | 查看本群前十名语录热度贡献者 |

::: tip
所有语录 ID 必须是大于零的整数；展示语录会带收录者昵称、点赞数、收录时间和编号。
:::

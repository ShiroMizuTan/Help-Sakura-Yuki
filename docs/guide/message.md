# 消息管理

## 撤回

| 指令 | 别名 | 示例 | 说明 |
|------|------|------|------|
| `撤回` | `撤回消息` / `收回` | `.撤回` | 撤回雪希在当前会话发出的最后一条消息 |

::: warning 三个前提
1. **只能在 QQ 群 / QQ 私聊里用**，QQ 官方那边不支持
2. 只能撤回**雪希自己**发的消息，撤不了别人的
3. 要在**同一个会话里**发指令 —— 群里发就撤群里的，私聊发就撤私聊的
:::

撤回成功后**不会有任何回复**，因为撤回本身就是回应。失败时会告诉你原因。

## 常见问题

**Q：提示「没有可撤回的消息」？**
可能是这几种情况：

- 雪希在这个会话里还没发过消息
- 要撤的那条已经被撤过了
- 距离发出太久，已经超过撤回时限

**Q：能撤回别人发的消息吗？**
不能，只能撤回雪希自己发的。

**Q：为什么要在同一个会话里发？**
撤回指令只认当前所在的会话。在 A 群发 `.撤回`，撤的是 A 群里雪希最后一条消息，不会影响 B 群。

## 自动撤回

色图（`.setu`）发出来的图片，可以设置成**过一会儿自动撤回**，避免刷屏。

默认是关着的，需要的话找管理员开一下，可以设置延迟多少秒撤回。

::: tip 目前只有色图支持
其他指令发出的图片不会自动撤回，想撤的话手动发 `.撤回` 就行。
:::

# 帮助、呼叫与程序状态

## 帮助

| 指令 / 触发方式 | 示例 | 说明 |
|-----------------|------|------|
| `帮助` / `Help` / `help` | `帮助` 或 `.帮助` | 返回帮助页与常见问题说明；支持无前缀 |

## 呼叫

| 指令 / 触发方式 | 参数 | 示例 | 说明 |
|-----------------|------|------|------|
| `雪希` / `Yuki` / `yuki` | 无 | `雪希`、`Yuki` 或实际 @ 机器人 | 单独发送名称，或单独实际 @ 当前机器人且不附带文本时，随机回复一条呼叫回复语；无自定义回复时返回"怎么啦？" |

### 呼叫回复管理

::: warning
以下指令仅管理员可以执行。
:::

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `添加呼叫回复` / `增加呼叫回复` / `添加回复语` | `内容` | `.添加呼叫回复 在的哦~` | 新增一条呼叫回复语；`\n` 会转为换行 |
| `查看呼叫回复` / `呼叫回复列表` / `回复语列表` | 无 | `.呼叫回复列表` | 按 ID 查看全部自定义呼叫回复语 |
| `删除呼叫回复` / `删除回复语` | `回复 ID` | `.删除呼叫回复 12` | 删除指定 ID 的呼叫回复语 |

## 程序状态

| 指令 | 示例 | 说明 |
|------|------|------|
| `ping` / `状态` | `.ping` | 采集机器人进程指标，生成并发送简洁状态卡片 |
| `具体状态` | `.具体状态` | 采集机器人进程指标，生成并发送详细状态卡片 |

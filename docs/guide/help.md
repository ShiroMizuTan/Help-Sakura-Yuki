# 帮助与呼叫

## 帮助

| 指令 / 触发方式 | 示例 | 说明 |
|-----------------|------|------|
| `帮助` / `Help` / `help` | `帮助` 或 `.帮助` | 返回帮助页与常见问题说明；支持无前缀 |

## 呼叫与 AI 对话

| 指令 / 触发方式 | 参数 | 示例 | 说明 |
|-----------------|------|------|------|
| `雪希` / `Yuki` / `yuki` | 无 | `雪希` 或 `Yuki` | 随机回复一条呼叫回复语 |
| `雪希` / `Yuki` / `yuki` | 文本 | `雪希 在干嘛` | 进入 AI 对话模式，支持图片输入 |
| `ai` / `AI` / `chat` / `聊天` | 问题 | `.ai 今天天气怎么样` | AI 对话，支持联网搜索和图片理解 |
| `清空AI历史` / `重置AI记忆` | 无 | `.清空AI历史` | 清除自己的 AI 对话记录 |

::: tip
单独发送「雪希」或 @ 机器人不附带文本时触发呼叫回复；附带文本时进入 AI 对话。AI 对话支持流式回复，可发送图片进行识别。
:::

### 呼叫回复管理

::: warning
以下指令仅管理员可以执行。
:::

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `添加呼叫回复` / `增加呼叫回复` / `添加回复语` | `内容` | `.添加呼叫回复 在的哦~` | 新增一条呼叫回复语；`\n` 会转为换行 |
| `查看呼叫回复` / `呼叫回复列表` / `回复语列表` | 无 | `.呼叫回复列表` | 按 ID 查看全部自定义呼叫回复语 |
| `删除呼叫回复` / `删除回复语` | `回复 ID` | `.删除呼叫回复 12` | 删除指定 ID 的呼叫回复语 |

## 程序状态

| 指令 | 示例 | 说明 |
|------|------|------|
| `ping` / `状态` | `.ping` | 查看机器人运行状态（简洁） |
| `具体状态` | `.具体状态` | 查看机器人运行状态（详细） |

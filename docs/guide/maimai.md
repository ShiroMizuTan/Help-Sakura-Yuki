# 舞萌 DX（maimai）

以下功能查询舞萌 DX 曲库、谱面、玩家成绩和牌子进度。所有指令都需要使用 `.` 前缀；歌曲名、用户名等包含空格的参数可使用中文引号包裹。

## 曲库与谱面

| 指令 / 格式 | 参数 | 示例 | 说明 |
|---|---|---|---|
| `查歌` | `歌名 [页码]` | `.查歌 初音` | 按歌名搜索；结果较少时直接列出，单曲时发送谱面信息卡，结果较多时发送分页图片 |
| `定数查歌` | `定数` / `最小定数 最大定数 [页码]`；或带 `+` 的等级 | `.定数查歌 13.7` 或 `.定数查歌 13+` | 按谱面定数搜索；`13+` 这类带 `+` 的写法按难度等级匹配 |
| `bpm查歌` | `BPM` / `最小BPM 最大BPM [页码]` | `.bpm查歌 180 200` | 按 BPM 搜索歌曲 |
| `曲师查歌` | `曲师名 [页码]` | `.曲师查歌 某某` | 按作曲 / 曲师搜索歌曲 |
| `谱师查歌` | `谱师名 [页码]` | `.谱师查歌 某某` | 按谱面设计者搜索歌曲 |
| `<别名>是什么歌` / `<别名>是啥歌` | `[页码]` | `.绿谱是什么歌` | 查询歌曲别名；别名重复时列出歌曲 ID |
| `id` | `歌曲 ID` | `.id 12345` | 按歌曲 ID 查询谱面信息卡 |
| `minfo` / `Minfo` / `info` | `歌曲 ID / 歌名 / 别名` | `.minfo 12345` | 查询自己的指定歌曲成绩；需要已绑定水鱼账号 |

::: tip
`查歌` 的类型也可以写作 `定数查歌`、`bpm查歌`、`曲师查歌`、`谱师查歌`。歌曲列表每页最多 25 首；谱面信息卡会显示曲名、作者、BPM、版本、难度、谱师和物量等信息。
:::

## 玩家成绩与账号绑定

| 指令 | 参数 | 示例 | 说明 |
|---|---|---|---|
| `b50` / `B50` | `[水鱼用户名]` | `.b50` 或 `.b50 玩家名` | 查询自己的 Best 50；也可指定水鱼用户名（用户名查询仅水鱼支持） |
| `ap50` / `AP50` | 无 | `.ap50` | 查询自己的 AP50；**仅落雪查分器支持**，需先用 `.绑定落雪` 完成授权 |
| `绑定水鱼` / `水鱼绑定` / `bindmaimai` | 无 | `.绑定水鱼` | 生成水鱼 OAuth 绑定链接；链接有效期 10 分钟 |
| `绑定落雪` / `落雪绑定` / `bindlxns` | 无 | `.绑定落雪` | 生成落雪 OAuth 授权链接（权限：读取玩家数据） |
| `数据源` / `maimai数据源` | `自动/水鱼/落雪` | `.数据源 落雪` | 设置自己的数据源偏好 |

::: tip
玩家成绩相关指令默认使用发送者 QQ；实际 @ 用户时查询被 @ 用户的 QQ。未绑定、用户不存在、拒绝授权、接口限流或服务异常时会返回对应提示。

数据源偏好（按用户独立存储，仅影响自己的查询）：
- `自动`（默认）：水鱼优先，失败自动切换落雪
- `水鱼`：查询优先使用水鱼查分器
- `落雪`：查询优先使用落雪查分器

当实际使用的数据源与偏好不一致时，BOT 会在回复中提示实际来源。

**AP50 与牌子查询没有备选数据源**（AP50 仅落雪、牌子仅水鱼），不受数据源偏好影响。
:::

## 谱面推荐

| 指令 | 参数 | 示例 | 说明 |
|---|---|---|---|
| `推荐` / `rec` | `[模式] [数量]` | `.推荐`、`.推荐 擦边`、`.推荐 补完 20` | 推荐接下来值得打的谱面；数量 1–30，默认 15 |

推荐基于你的 B50 成绩计算「打到下一评价档」的收益，六个模式的候选集互不重叠：

| 模式 | 说明 |
|---|---|
| `吃分`（默认） | 已游玩、推到 SSS（100）/ SSS+（100.5）收益最大的谱面，按有效差距升序 |
| `擦边` | 已游玩、距 SSS / SSS+ 不足 0.5% 的谱面，按差距从小到大 |
| `水分` | 定数高于拟合定数的谱面（比标称好打、给分却按定数算），按差值从大到小 |
| `新歌` | 只算当前版本新曲（记入 B15），推到 SSS/SSS+ 收益最大的 |
| `旧曲` | 只算非当前版本谱面（记入 B35），推到 SSS/SSS+ 收益最大的 |
| `补完` | 完全没打过、难度落在 B50 定数中位数 ±1.0 的谱面，按打完的 B50 预期增量降序 |

::: tip
rating 只在评价档跳变时增长，所以推荐目标永远是「推到下一档」而不是某个百分比。增量统一按 B50 边际计算：已在榜内的谱面减自身当前值，不在榜内的减门槛值。
:::

## 定数表与完成表

| 指令 / 格式 | 参数 | 示例 | 说明 |
|---|---|---|---|
| `<等级>定数表` | 等级 `7` 至 `15`（可带 `+`） | `.13+定数表` | 发送指定等级的定数表；低于 7 的等级不支持 |
| `<等级>[fc/fc+/ap/ap+]完成表` | 等级 `7` 至 `15`，可选完成计划 | `.13ap完成表` | 查询指定等级的成绩完成表；可选 FC / AP 计划 |
| `<版本><牌子>完成表` | 版本 + 牌子 + 可选页码 | `.紫将完成表` | 查询指定版本牌子完成表 |
| `<版本><牌子>进度表` | 版本 + 牌子 + 可选页码 | `.紫将进度` | 查询指定版本牌子进度 |
| `<等级> <评价>进度` | 等级、评价、可选分类和页码 | `.13 s 进度` | 查询指定等级的评价进度 |
| `<定数>分数列表` | 定数 + 可选页码 | `.13.0分数列表` | 查询指定定数的分数列表 |

### 牌子版本与评价

::: tip
牌子版本支持真、超、檄、橙、暁/晓、桃、櫻/樱、紫、菫/堇、白、雪、輝/辉、舞、霸、熊、華/华、爽、煌、宙、星、祭、祝、双、宴、镜、彩等写法。牌子计划常用 `者`、`極/极`、`将`、`神`、`舞舞`。

`舞` / `霸` 版本需要跨全部 SD 版本拉取游玩记录（走水鱼 `/player/plate` 的版本列表，单请求完成），曲目表按「舞」牌口径判定，耗时略高于其他版本。进度表与完成表会按难度分别列出「余」的谱面数。

评价进度支持评价等级（如 `s`、`ss`、`sss`、`ap`、`fc`、`fs`、`fdx` 及其 `+` 写法），分类可选 `已完成`、`未完成`、`未开始` / `未游玩`。
:::

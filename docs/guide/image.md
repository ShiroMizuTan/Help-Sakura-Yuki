# 图片

## 看图

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `看图` | 无 | `.看图` | 获取随机图片（默认 auto 模式） |
| `看图` | `类型` | `.看图 pe` | 指定类型获取图片 |

## 支持的图片类型

| 类型 | 说明 |
|------|------|
| `auto`（默认） | 自动选择图片来源 |
| `pc` | PC 端图片 |
| `pe` | PE 端图片 |
| `avatar` | 头像类图片 |
| `random` | 随机来源 |

::: tip
图片获取流程：获取 URL → 下载到临时文件 → 发送图片 → 删除临时文件。
:::

# 反馈

## 提交反馈

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `反馈` / `提交反馈` / `bug反馈` / `bug` | `反馈内容` | `.反馈 希望增加积分排行榜` | 提交用户反馈 |

## 管理反馈

::: warning
以下指令仅管理员可以执行。
:::

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `查看反馈` / `反馈列表` | 无 | `.查看反馈` | 查看最近 20 条反馈 |
| `处理反馈` | `反馈 ID` | `.处理反馈 15` | 将指定反馈标记为已处理 |

## 指令调用统计

::: warning
以下指令仅管理员可以执行。
:::

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `指令统计` / `命令统计` / `调用统计` | `[条数]` | `.指令统计` 或 `.指令统计 30` | 按调用次数倒序查看指令排行 |

- 不填条数时默认输出**前 15 条**，最多可以看 **50 条**
- 列表按调用次数从多到少排列，每条带调用次数和占比
- 末尾会显示最近一次使用这条指令的时间

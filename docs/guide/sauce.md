# 搜图

溯源一张图片的来源：找出它的画师、出处，或者是哪部番剧的截图。

## 使用方式

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `sauce` / `搜图` / `识图` | 无（图片同条消息） | 图片 + `.搜图` 同条发送 | 溯源本条消息中的第一张图片 |
| `sauce` / `搜图` / `识图` | `图片URL` | `.搜图 https://example.com/img.jpg` | 溯源指定直链图片 |

::: tip
图片必须和指令**在同一条消息**里发送（先贴图再打字会分成两条，不生效）。
也可以直接给图片直链，不用上传图片。
:::

## 返回内容

- 相似度、标题、作者与原始链接（最多 3 条）
- 附带最佳匹配的缩略图

## 数据源

| 优先级 | 数据源 | 擅长 |
|------|------|------|
| 主源 | SauceNAO | 插画 / 漫画（Pixiv、Danbooru 等索引） |
| 备源 | trace.moe | 番剧截图识别（返回番剧名 / 集数 / 时间点） |

主源失败或无结果时自动降级到 trace.moe。

::: warning
- 必须带 `.` 前缀才会触发，不支持无前缀匹配
- 仅 QQ 群聊 / 私聊可用，QQ 官方渠道不解析收到的图片消息

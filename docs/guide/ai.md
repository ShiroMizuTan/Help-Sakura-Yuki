# AI 对话

雪希可以和你自由聊天，也会记住关于你的事。

## 开始对话

| 触发方式 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `ai` / `chat` / `聊天` | `内容` | `.ai 今天天气怎么样` | 带前缀发起对话 |
| `雪希` / `yuki` | `内容` | `雪希 在干嘛` | 呼叫名 + 内容，**支持无前缀**，群聊里直接发送即可 |

::: tip
只要带内容，呼叫名后可以不写前缀。例如群里直接发 `雪希 陪我聊会儿` 就会触发。
但只发呼叫名（如单发一句 `雪希`）不会进入对话，而是随机回一条呼叫回复语。
:::

## 支持的输入

| 类型 | 示例 | 说明 |
|------|------|------|
| 文字 | `.ai 推荐一首歌` | 普通对话 |
| 图片 | 发送 `.ai` + 图片 | 会描述图片内容；纯图无文字时也会自动处理 |
| 图片 + 文字 | `.ai 这张图好看吗` + 图片 | 结合图片和文字回答 |

## 它会记住你

聊天中提到的**长期偏好、身份信息、正在进行的计划和目标**会被自动记住，
之后聊天时能自然地用到，不需要重复说明。

- 只记关于你的**稳定事实**，比如「我平时都用中文」「我在准备考研」
- 不会记一次性问题、临时情绪、闲聊内容
- 记忆按用户隔离，**私聊的内容不会出现在群里**
- 群聊里产生的记忆会进群共享池，同群所有人都能受益

## 会不会跨群泄露我的信息

不会。私聊记忆只有你和雪希知道。
群聊中属于**别人**的记忆在注入时会被标注，雪希不会把你的事当作别人的来回答，反之亦然。

## 清空对话历史

| 指令 | 示例 | 权限 | 说明 |
|------|------|------|------|
| `清空AI历史` / `清空聊天记录` / `重置AI记忆` | `.清空AI历史` | 所有人 | 清空与雪希的聊天上下文 |

::: warning
该指令清空的是**对话上下文**（近期聊天记录），让它忘记刚才聊过什么。
已经形成的长期记忆不会被删除。
:::

## 管理员指令

以下指令仅管理员可用，用于观察记忆系统的运行状态。

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `记忆状态` / `AI记忆状态` | 无 | `.记忆状态` | 查看记忆池条数与可用性 |
| `记忆检查` / `AI记忆检查` | `文本` | `.记忆检查 我喜欢喝美式` | 用给定文本试跑一次召回，回显命中分数与内容 |
| `人设` / `人设状态` / `AI人设` | 无 | `.人设` | 查看核心人设注入状态 |
| `人设检查` / `AI人设检查` | `文本` | `.人设检查 雪希你的生日是什么时候` | 用给定文本试跑一次细节检索 |

### 记忆状态

输出记忆系统的可用性与各记忆池条数：

- **个人记忆池**：当前用户自己的记忆条数
- **本群共享记忆池**：该群所有人共享的记忆条数（仅群聊显示）
- 召回门槛：当前生效的条数与相似度阈值

### 记忆检查

用来诊断「为什么它没想起某件事」。会列出检索到的记忆、相似度分数和是否达到阈值：

| 标记 | 含义 |
|------|------|
| `+` | 分数达到阈值，线上会被注入 |
| `-` | 分数低于阈值，线上会被挡掉（检索到了但没用上） |

分数列显示 `原始相似度 → 加权后排序分`，并附记忆年龄。
排序会参考记忆的新鲜度，所以只看原始分会和实际顺序有出入。

群聊中会同时列出个人池与群池的结果，便于确认命中的是哪个池。

### 人设状态

雪希的「人设」分两部分：每轮对话都会带上的**核心设定**，以及需要时才检索的**细节设定**。

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `人设` / `人设状态` / `AI人设` | 无 | `.人设` | 查看核心人设注入状态：各段字数、占位符是否存在 |
| `人设检查` / `AI人设检查` | `文本` | `.人设检查 雪希你的生日是什么时候` | 用给定文本实跑一次细节检索，回显命中分数与内容 |

**为什么需要这两个指令**：人设出问题是不报错的。核心设定靠每轮注入生效，细节设定靠提问时才检索，
这两条路任何一条断了都不会抛异常，从聊天界面上看只会表现为「她说话不像她了」——
很难判断是配置问题还是她今天就这样。`.人设` 把这些内部状态直接摊开给你看。

`.人设` 会对这两种配置错误**明确告警**：

- 核心设定里有某段在分段配置里找不到 → 列出全部缺失的段
- 系统提示里没有核心人设的占位符 → 核心人设根本进不了每轮对话

`.人设检查` 的判定标记与 `.记忆检查` 一致：`✓过线` / `✗被阈值挡掉`。

::: tip
`.人设检查` 只能验证**细节段**的召回质量。核心设定每轮都注入，不走检索路径，
它的健康状况要看 `.人设`。
:::

## 常见情况

| 情况 | 说明 |
|------|------|
| 短消息没生效 | 太短的消息不会触发记忆检索，正常说话即可 |
| 说了一遍没记住 | 只有长期稳定的信息才会被记，一次性内容不会存 |
| 记忆条数不增长 | 重复提到同一件事会刷新已有记忆而不是新增；闲聊不会产生记忆 |
| 群里问它我的喜好 | 群聊会同时看你的个人记忆和本群共享记忆 |

::: tip
记忆系统完全自动运行，不需要手动录入。正常聊天就行。
:::

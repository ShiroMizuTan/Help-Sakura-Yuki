# 更新日志

## 添加更新日志

::: warning
仅管理员可以执行。
:::

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `添加更新日志` / `新增日志` | `版本 类型 内容` | `.添加更新日志 1.2.0 Feature 增加情侣系统` | 添加更新日志 |

## 查看更新日志

| 指令 | 参数 | 示例 | 说明 |
|------|------|------|------|
| `更新日志` / `版本日志` / `changelog` | 无 | `.更新日志` | 查看最近更新日志（以转发消息展示） |
| `更新日志` / `版本日志` / `changelog` | `版本` | `.更新日志 1.2.0` | 查看指定版本的更新日志 |

## 支持的日志类型

| 类型 | 说明 |
|------|------|
| `Feature` | 新功能 |
| `BugFix` | 修复 |
| `Breaking` | 破坏性变更 |
| `Refactor` | 重构 |
| `Improve` | 改进 |
